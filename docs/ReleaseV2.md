# SynLove v2.0 使用与验证说明

发布日期：2026-11-03。主程序版本：SynLove-Personal-Agent v2.0。

## 升级内容

主接待会话与后台执行会话分别使用人格、工具和上下文。后台通过任务记录提交结果，由主接待会话整理后进入原有发送队列。已存在的时间线、人物图谱和通道状态继续使用实例自己的数据目录；升级不需要清空个人记录。

首次使用请按主 README 配置自己的模型和通道；已有安装应保留配置与 runtime，避免同时启动新旧两套消费者。模型与业务服务的 `external` 配置只连接现有服务，不会在本机补启另一个实例。

## 验证范围

- 隔离测试覆盖 QQ/微信同时入站、重复消息、通道状态隔离、租约竞争、重启恢复和重复完成通知去重。
- 后台任务测试覆盖实际 Harness 会话、工具隔离、并行任务、超时、取消、完成后人格整理及整理失败重试。
- 时间线测试覆盖一千条记录追加与去重、索引损坏重建、推理默认排除、摘要失败保留及恢复。
- 图谱测试覆盖远端失败不推进水位，同毫秒新增记录不会被跳过。
- 技能测试覆盖中文格式、写入、待审更新、写入失败上报、远程 Gemma 配置复用和实例目录。
- 自修测试使用隔离目录及可控编码器，验证真实子进程启动、静态检查、坏修改回滚、互斥和冷却；不让测试编码器修改生产代码。
- 真实接口验收使用人工素材，验证远程 Gemma 摘要与人物图谱、云端记忆路径、TTS 合成、ASR 转写和固定 Windows CMD 命令。

### 本轮发现与修正

- Windows 进程探活不再使用可能产生信号副作用的 `os.kill(pid, 0)`。
- 自修补齐日志脱敏模块和 JavaScript/TypeScript 静态检查，验证失败时回滚。
- 技能定时复盘修正完整项目路径匹配，支持连字符、中文及多帧压缩；读取失败不再当成空素材。
- 技能降级请求明确无工具输出协议；技能保存失败不再虚报成功或推进游标。
- 时间线拒绝空模型正文，摘要调度异常后正确释放运行标志。
- 音频接口拒绝鉴权时有限排空请求体，避免 Windows 下连接复位掩盖 401。

某公开站点的证书链验证失败，换另一公开站点后网页采集与 Gemma 整理通过；保留 TLS 验证，没有以关闭安全校验换取成功。一次远程提醒调用失败，随后独立创建、查询与删除验收通过；首次失败原因未获得完整证据，不判定为已经消除所有网络瞬态错误。

## 2026-11-03 · 任务来源校验修复

生产环境的时间插件会在每个模型步骤追加 `user/message` 快照。旧校验误将其当成缺少授权来源的真实输入，导致任务工具报错。现仅跳过宿主 `time-context` 插件的快照，继续查找本轮真实入站；未知来源、失效来源、后台结果与跨轮权限仍拒绝。

修复回归共 14 项通过，并在 Harness 集成及真实模型烟测中加载实际时间插件。真实闭环使用 5 次模型请求完成提交、执行、结果整理与隔离队列投递，未向真实平台发送测试消息。首次真实测试触发测试脚本字节预算保护，调整该测试预算后通过；请求数与 token 上限保持有界。

## 2026-11-03 · 后台研究与结果回传修复

研究任务新增受限 `save_report` 工具，报告保存在当前实例的 `runtime/agentTasks/reports`，不向研究角色开放任意路径写入或命令执行。执行协议明确使用宿主提供的工作目录，结果摘要与完整报告分别保存。

Worker 的 `web_search` 改用现有安全网络服务获取 Bing RSS 搜索结果，不再由默认 DeepSeek 搜索工具要求额外密钥。搜索片段仅用于发现来源，不等于来源正文已经核实；网络失败仍如实返回错误。

每次结果整理及重试创建独立会话，继承当前主人格提示词，读取任务结果而不继承上次未发送草稿。整理超时调整为 180 秒，正常完成后才进入发送队列；完整执行总结预先归档，大结果超过注入上限时明确标记节选。

23 项任务与人格回归通过，覆盖工具权限、路径限制、报告完整保存、搜索服务注入和超时草稿重试。真实 Qwen 模型使用 6 次请求完成建任务、搜索、读取样本、保存报告及主人格整理，报告用量合计 7,143 token，结果进入隔离队列。该验证未向真实微信或 QQ 发送测试消息，也不代表搜索结果中的事实均已核验。

## 使用边界

多实例保护在相同状态目录与租约范围内生效；复制整个安装到另一份数据目录并重复配置同一平台账号，仍可能造成外部消费者冲突。

消息队列和通知确认降低重复发送风险，但公网发送成功后、本地确认前崩溃的窗口仍受平台是否提供幂等接口影响。微信主动消息受平台上下文窗口约束，不能保证任意离线时间后主动送达。

自动修复不依赖对话 Agent，但需要可用的编码 CLI、授权和网络。静态检查通过不能证明业务语义正确，修复后仍须业务探针验收。技能格式校验和图谱解析也不能证明模型生成事实完全准确；技能更新默认待审，人物关系应按需要复核。

远程健康检查不执行付费生成。节点注册与健康响应表明链路和接口可用，不能保证大任务不会超时；低显存 TTS 冷启动可能需要数分钟。
