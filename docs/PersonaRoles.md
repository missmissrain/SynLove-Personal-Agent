# 主人格与后台执行提示词

“人格与工具”提供两个独立编辑框。

| 编辑框 | 职责 | 保存后何时生效 |
| --- | --- | --- |
| 欣爱 · 主人格 | 聊天、接待、任务委派、读取总结后组织回复 | 重启 Agent 内核 |
| 执行 Agent · 任务提示词 | 独立任务中的操作、验证、自纠错和正式总结 | 下一次创建任务；不改变正在运行的任务 |

主人格沿用 `config/weixinDoubaoProfile.patch.yml` 的 `personaPrefix`，避免同时维护两份运行源。发行版初次初始化从 `prompts/XinAi.md` 填入默认主人格。执行提示词来自 `prompts/TaskExecution.md`，每个新任务创建独立会话时读取，不继承主人格的聊天风格。

GUI 的 `GET /api/persona?role=presenter|worker` 与 `POST /api/persona` 使用固定角色白名单。保存正文为 `{ "role": "worker", "text": "..." }`；旧调用省略 role 时仍指主人格。保存会备份源文件，再原子替换，避免后台读取半份正文。

`prompts/PresenterProtocol.md` 和 `prompts/WorkerProtocol.md` 是宿主协议，不出现在人格编辑框。前者规定任务接单与结果表达，后者规定执行权限、结果状态和正式总结格式。可编辑提示词不替代代码中的工具权限限制。

主人格默认使用一两句自然口语；完整任务要求交给执行者，接单通知不复述任务书。长报告先说明主要结果与关键限制，按用户需要展开。人格包含性格、语气词、玩笑尺度、记忆真实性和表情使用规则；后台执行提示词保持独立。

当前主人格开放五个任务工具，以及 timeline_days、timeline_search、timeline_read、relation_query 四个只读记忆工具。回忆对话和人物关系可直接完成，不必派后台任务。写入、摘要和图谱更新仍由原维护流程处理。主会话没有直接发送图片的工具，不能用文字占位冒充表情包，Emoji 可以作为普通文字使用。

后台终态先持久化，通知桥等待主人格空闲，使用当前主人格提示词创建独立的短表达会话。该会话不继承主聊天历史与失败草稿，只读取当前任务结果；每次失败重试都创建新会话，默认180秒超时，完整生成后才进入原通道队列。用户聊天和后台执行继续使用各自原会话。

润色失败、空回复或超时不会透传执行原文，而是保留待办，按30秒至5分钟的退避间隔重试。已生成正文但通道入队失败时，复用保存的正文，避免重复生成。退避计数保存在进程内，重启后从持久待办继续处理；内核停止时会取消正在生成的通知。

执行者统一使用全部已配置的执行工具与业务MCP，不再按任务类别裁剪；旧配置的toolAllow不再影响权限，旧任务参数兼容接收。执行者仍不直接发送通道消息、不再派生执行者。同一工作区的任务串行执行，避免原研究任务获得写权限后互相改文件。

执行者可用 `save_report` 保存本任务完整报告，工具固定写入 `runtime/agentTasks/reports`，不接受路径参数。通知前宿主还会完整归档执行总结，避免旧任务仅有长总结而没有文件；`task_result` 同时返回真实产物位置。长报告与给主人格阅读的短总结分别保存。

后台 `web_search` 使用现有安全HTTP传输读取公共Bing RSS，最多四条查询、八个去重来源，不依赖DeepSeek搜索密钥，也不修改聊天模型或宿主搜索配置。网络失败、非RSS响应与访问限制仍会如实报错，搜索摘要需要读取原文进一步核验。

旧版提示词可使用 `node tools/SeparatePersonaPrompts.mjs` 预览迁移范围，显式加 `--apply` 才会备份并剥离旧底层操作章节。脚本保留已有性格与聊天章节，重复运行不会继续追加规则。
