# GUI 与三维人物集成发布说明

更新日期：2026-11-03。

## 安装与使用

本版基于主分支生产修复提交 `3a98ea2`，保留此前任务来源识别、工具参数错误提示和设置兼容性更新。更新本仓库后沿用原有启动入口和配置，无须新增模型服务。

首页左侧显示欣爱，右侧为真实运行信息。人物自动播放眨眼、呼吸、轻微发梢摆动和点头、侧头、左右看看、轻抬手四种小动作，无需点击触发。人物区使用无光照渲染，保留明亮白发并提高粉色与眼睛的色彩区分。

桌面布局固定人物和底部品牌落款，右侧内容独立滚动。窄屏切换为纵向布局。设置、人格和远控内容分组展示；请求期间显示等待反馈，停止操作使用自绘确认框。

## 运行资源与要求

- `console/public/Avatar/assets` 包含网格、原贴图、静态回退图与品牌派生图，总计约 60 MB。
- 渲染依赖本地固定版本 Three.js r170，许可证位于 `console/public/Avatar/vendor/LICENSE.txt`。
- 需要 WebGL2；资源加载失败时回退为静态图，其他页面仍可使用。
- 默认每秒 30 帧，设备像素比上限 1.5；隐藏页面和离开首页时暂停渲染。系统启用减少动态偏好时停止自主骨骼及发梢运动。
- 不包含源建模工程、第三方动作包或模型权重。当前运行格式是本项目的骨骼网格格式，不能直接载入任意 VRM、GLB 或动作包。

## 验证与边界

实际浏览器页面验证覆盖 WebGL2、七个渲染部件、眨眼恢复、内部口型预览、页面切换暂停、资源失败回退，以及六档窗口尺寸。桌面布局滚动时人物与落款位置保持一致。

人格页使用临时提示词存储验证分栏切换、独立保存、未保存内容保留、重新读取与空提示词拒绝，不写入生产人格。现有四项生产回归检查通过，覆盖会话恢复边界和假网络下的 QQ 鉴权、心跳及重连顺序；这不代表真实平台端到端验收。

确定性十分钟模拟覆盖全部四种小动作，未出现连续同类动作或非有限骨骼矩阵；逐项动作边长与位移筛查通过，各动作均平滑回到待机。该检查不等于完整碰撞检测，也不代表任意外部动作可以安全播放。

最新调色在相同姿势的实际画布采样中，蝴蝶结区域 HSV 饱和度约 16.1%，头发平均亮度约 229/255。GPU 标准 sRGB 色块往返误差为 0；场景无灯光。

本次不连接真实消息平台、不调用模型，也不修改账号和后台服务配置。界面测试不代替微信、QQ、远程服务的业务验收。尚未实现音频驱动口型、任务驱动动作、完整发丝或衣物碰撞。
