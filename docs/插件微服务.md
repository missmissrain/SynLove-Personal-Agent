# 插件微服务（8830）

## 定位

音乐、桌面、爬虫这类「可被反复调用的工具」统一收进一个微服务，调用方只认一个端口、一套 JSON API。
插件只做能力适配，不持有调度权（什么时候调用由调用方或 8820 决定）。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 存活与插件数量 |
| GET | `/v1/plugins` | 插件目录（名称、描述、动作、参数） |
| POST | `/v1/plugins/{plugin}/{action}` | 调用动作，body 为参数对象 |

返回统一为 `{"ok": true, "plugin": ..., "action": ..., "value": ...}`；
参数错误 400、插件或动作不存在 404、依赖不可用 503、实现异常 500，错误信息直接可读。

## 目录结构

```
plugins/
├── PluginRegistry.py        按配置加载插件
├── PluginService.py         统一 HTTP 入口
├── McpHttpClient.py         MCP 传输（Windows 共用）
├── music/
│   ├── MusicPlugin.py       酷狗交互类
│   └── kugou/               酷狗实现（API 客户端、队列、远控播放、MCP、登录）
├── windows/
│   ├── WindowsPlugin.py     桌面交互类
│   └── WindowsDesktopService.py  桌面 MCP 启动器
└── crawl/
    ├── CrawlPlugin.py       RSSHub/网页交互类
    └── rsshub/              RSSHub 安装脚本
```

实现与交互类放在同一个功能目录：交互类只管协议与参数，实现仍是原来的代码，只是换了位置。

## 已登记插件

| 插件 | 动作 | 依赖 |
|---|---|---|
| `music` | `search`、`play`、`control`、`status`、`playlists`、`playlist_tracks`、`play_playlist` | 酷狗 API（`plugins/music/kugou/config/kugou.json`）、终端播放器 |
| `windows` | `tools`、`call` | `windows_mcp`（`config/windowsMcpConfig.json`，17865/mcp） |
| `crawl` | `feed`、`fetch` | RSSHub（默认 1200）与任意 http/https 页面 |

示例：

```bash
curl -X POST http://127.0.0.1:8830/v1/plugins/music/search      -H "Content-Type: application/json" -d "{\"query\":\"晴天\",\"limit\":2}"

curl -X POST http://127.0.0.1:8830/v1/plugins/crawl/feed      -H "Content-Type: application/json" -d "{\"route\":\"/zhihu/hot\",\"limit\":3}"

curl -X POST http://127.0.0.1:8830/v1/plugins/windows/call      -H "Content-Type: application/json" -d "{\"tool\":\"App\",\"arguments\":{}}"
```

## 新增一个插件

1. 在 `plugins/<功能>/` 下新建一个交互类，提供 `description`、`actions()`、`call(action, payload)`；
2. 在 `config/plugins.json` 的 `plugins` 里加一条 `{name, module: "plugins.<功能>.<类文件>", class}`；
3. 重启 `SynLove-PluginService`。

插件类只写适配，不写定时器；需要周期执行的放到自迭代服务。

## 边界

| 内容 | 归属 |
|---|---|
| 工具调用（音乐、桌面、爬虫） | 本服务 |
| 什么时候跑（预演、维护、提醒） | 自迭代服务 8820 |
| 进程存活与拉起 | 事实层看门狗 |
| 消息收发 | 消息服务 8805/8812 |

## 已知依赖

- 酷狗 API 与播放器由 `plugins/music/kugou/client` 提供；`play` 失败会返回真实原因（例如目标电脑离线）。
- `windows` 走 MCP streamable HTTP，token 取自 `config/windowsMcpConfig.json`。
- `crawl` 限制 2MB、20 秒，只允许 http/https。
