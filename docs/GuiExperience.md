# GUI 交互与视觉更新

更新日期：2026-11-03。

界面沿用粉白配色、圆角窗口与品牌资产，统一卡片间距、边框、按钮和输入控件。主操作采用实色粉色按钮，普通操作使用浅色按钮，停止等危险操作保留独立提示。

## 操作路径

左栏按“日常”“连接与能力”“运行与诊断”组织。诊断默认折叠，通过首页统计卡或动态入口访问明细时自动展开对应分组。

当前首页左侧为固定人物区，右侧按照统计摘要、消息与连接、能力与服务及待办动态的顺序排列。桌面窗口右侧独立滚动，人物与品牌落款保持固定；窄屏改为纵向布局。后端服务固定每页五项，通过箭头翻页。

统计摘要可直达用量、调用记录、系统和记忆页，服务旁的配置入口直达后台服务设置。导航切换到新页面时从顶部开始，返回已访问页面时恢复该页的位置。

人格页分为“欣爱主人格”“执行内核”“工具与能力”，一次展示一个区域；保存与重新读取位于编辑区上方。分类切换保留未保存的文本，支持左右键与 Home、End。服务与远控页分别展示“后台服务”和“远控电脑”，避免两种连接配置混在一起。模型页默认展示选择与现有模型，自定义添加表单按需展开。

## 等待与失败

用户点击触发请求时，顶端显示不确定进度条，对应按钮显示等待标记并阻止重复提交。刷新首页、端口查验和内核重启会持续跟踪整段操作，而不只跟踪第一条请求。

等待条只表示请求仍在进行，不显示虚构的完成百分比，也不将“请求返回”当成后台任务已经完成。自动心跳和定时刷新不触发这类前台提示。失败时显示可关闭的文字提示，不自动重试。

停止内核使用自绘确认框，默认聚焦取消按钮；取消或按 Escape 不会提交停止请求。开启操作系统的减少动态效果偏好后，关闭切页和等待条动画，保留静态等待反馈。

## 验证范围

人物接入前，使用现有 Electron 运行真实页面，完成 34 项检查：全部 13 个页面的导航与横向布局、1280×720 与 1024×576 尺寸、当时的首页关键区域首屏可见、五项服务分页、请求等待和防连点、失败文本安全展示、提示关闭、后台刷新不干扰、确认框取消、滚动位置恢复、分类键盘切换与未保存文本保留，以及减少动态效果。

本次人物接入后，重新验证六档窗口尺寸、人物固定与右侧滚动、人物加载与回退、页面切换暂停及人格分栏的独立保存。最新检查使用实际浏览器访问控制台，不表示本次已经重启或重新验收 Electron 桌面窗口；范围见 [界面集成发布说明](GuiRelease.md)。

请求反馈故障使用页面内的隔离 Promise 注入；没有保存测试配置、执行停止操作或向微信和 QQ 发送测试消息。该检查验证 GUI 行为，不代替消息通道与远程服务的业务验收。
