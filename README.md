欣爱是一个跑在自己机器上的私人智能体：她有自己的声音、自己的判断、自己的记忆，
通过微信、QQ 和语音与你相处，也能调度你家里的电脑、手机与模型服务。

v3.0 是一次彻底的结构重构：代码、配置、数据、资产、技能全部按职责分层，
服务之间只通过 HTTP 与明确的接口交互，不再有「改一个文件、四处行为变化」的耦合。

---

## 她是谁

欣爱不是聊天框，是一个跑在自己机器上的私人智能体：

- **自迭代**：预演、复盘、沉淀技能、夜间维护、改自己的代码
- **多终端推理**：设备状态、屏幕、摄像头、定位、音频路由一起推理
- **完善的权限**：家里的电脑、手机、服务器都是她的终端，能执行、能看、能放声音
- **冲浪功能**：订阅、抓网页、用浏览器查、下载视频并摘要
- **数据库与长期记忆**：时间线、知识图谱、人物画像、会话上下文
- **音频交互**：唤醒词、流式识别、固定声线、播放前复核

## 自我迭代与自编码

这是她和其他助手的根本区别：**她会改自己，而且有完整的验证与回滚**。

1. **预演**：从记忆里发现新信息，先在隔离环境里走一遍，不直接动生产。
2. **沉淀**：预演通过后，把流程写成正式技能；技能有评审、有版本。
3. **夜间维护**：检查代码、修复明显缺陷、整理文档；不打断白天的主链路。
4. **自编码**：在独立分支修改自己 → 跑静态检查与验收测试 → 生成补丁 →
   汇报并等待确认 → 确认后合并回生产。
5. **调度**：预演、技能、维护、记忆更新统一由自迭代服务排期，失败重试、状态落盘。

## 在场与位置推理

- 采集：设备在线、空闲、锁屏、前台窗口、地点、日程、摄像头是否有人、音频输出路由
- 推理：模型判断 + 规则兜底，输出唯一的「主人在哪、该用哪台设备」
- 监听：只在目标设备声明采音能力时开启，目标变化立即停止
- 主动：先判断是否适合打扰，再复核设备与去向；过期语音直接丢弃

## 终端与设备

- **服务器**：本机能力、模型、文件、屏幕
- **PC 终端**：采音、播放、KWS、文件、软件启动、远控
- **安卓终端**：横屏人物桌面、通知、定位、摄像头、音频路由、GUI 控制
- 统一协议：注册、心跳、能力表、签名指令、真实回执
- 设备离线时语音/消息进信箱，上线后投递
- 文件分块传输、断点、校验；传输日志脱敏

## 爬虫与内容

- **RSSHub**：订阅源抓取
- **网页抓取**：正文抽取、限体积与超时
- **浏览器驱动**：Edge 打开页面、检索、读取结果
- **视频**：下载、转写、摘要
- **日报**：定时采集 → 模型筛选 → 推送

## 记忆与人格

- 时间线：按天记录对话与事件，可检索、可摘要
- 知识图谱：人物、关系、偏好、事件的结构化沉淀
- 人物画像：从长期互动中提炼，不写死
- 会话持久化：重启不丢上下文，按用户隔离

## 语音

- 唤醒词检测在终端本地完成
- 流式识别、固定声线合成、长文本分段
- 播放路由与播放前复核；耳机/扬声器不擅自切换

## 工具插件

音乐（酷狗搜索/点歌/控制）、Windows 桌面（窗口/输入/系统操作）、
RSSHub 与网页抓取，统一成一套插件 API，按能力调用。

## 架构

四层职责，层间只走 HTTP 与固定接口：

| 层 | 职责 |
|---|---|
| 消息微服务 | 微信、QQ、语音的收发、投递回执、通道状态、ASR 开启 |
| 事实微服务 | 在场、位置、监听目标、设备状态采集、服务看门狗 |
| 自迭代微服务 | 预演、技能沉淀、代码维护、图谱与时间线、主动研究、定时任务 |
| 插件微服务 | 音乐、桌面、爬虫等工具能力 |

外围是模型服务与各类终端。端口、地址与设备身份全部由部署配置决定。

## 快速开始

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt

# 配置放在部署根 models/config：
#   modelConfig.json / serviceConfig.json / secrets.json
.venv\Scripts\python.exe start_stack.py
```

## 日志与路径

- 日志：生产根 `runtime/logs/`，`all.log` 汇总，每服务单独一份
- 路径：库内相对路径，统一由 `services.ProjectPaths.resolve` 解析
- 机器相关项只放部署环境变量，不进仓库

## 安全与脱敏

- 仓库不含密钥、私钥、配对信息、设备身份、端口与真实地址
- 配置示例只放占位符；真实配置在部署根 `models/config/`
- 日志不写正文，令牌与 openid 一律脱敏
